# Plesuj – MVP
Statický web. Název/e-mail: `config.js`. Data: `python3 scripts/build_data.py /workspace/plesy/plesy_khk.csv` → `data/plesy.json`, `data/psc.json` (PSČ z tools/souradnice_obci.csv, zdroj github.com/33bcdd/souradnice-mest, doplněno o přesné polohy plesů).
Lokálně: `python3 -m http.server 8080`.
